Custom Sections (Optional)
Every section below is fully optional and works the same way: add or remove as many rows and columns as you need, and an empty row/column simply won't appear on the live page. The three quick-start buttons just pre-fill a table with a sensible headline and column names — you can rename or add to them afterwards, exactly like any other Custom Section. In a table cell, you can either type [word](https://url) in the cell's text to make just that word clickable, or tick the cell's 🔗 Link checkbox to make the whole cell clickable — if you use both in the same cell, the 🔗 Link checkbox's address wins and the cell links there.
